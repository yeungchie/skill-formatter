*skillfmt.txt*  Format SKILL source with skillfmt

Requires Vim 7.4 or newer and the |skillfmt| command on $PATH.

INSTALL

Vim 7.4 has no package directory support.  Copy plugin/, autoload/,
ftplugin/, ftdetect/ and doc/ into a runtime directory (Unix ~/.vim,
Windows ~/vimfiles), then run:

    :helptags ~/.vim/doc

Vim 8+ may use a package directory such as
~/.vim/pack/plugins/start/skillfmt/.  Set |g:skillfmt_executable| when
the executable is not on $PATH.

COMMANDS

                                                        *:Skillfmt*
:Skillfmt               Format the whole buffer.

                                                        *:SkillfmtRange*
:[range]SkillfmtRange   Format the selected lines as a fragment.
                        The whole buffer is sent to skillfmt with --lines, so
                        only the selected lines are replaced and text outside
                        the range is preserved byte for byte.  The selected
                        lines must form a complete fragment; otherwise they
                        are left unchanged with a diagnostic.

                                                        *:SkillfmtRefresh*
:SkillfmtRefresh        Rebuild 'formatprg' after changing
                        |g:skillfmt_executable| or |g:skillfmt_args|, or after
                        upgrading skillfmt.

                                                        *:SkillfmtVersion*
:SkillfmtVersion        Show the detected skillfmt version and the minimum
                        required version.

FILTERS

  :%!skillfmt format    Format the whole buffer through the CLI filter.
  :'<,'>!skillfmt format
                        Format a fragment; the formatter auto-detects its base
                        indentation and echoes the input unchanged on error.

OPTIONS

  g:skillfmt_executable  Path to the executable. Default: "skillfmt".
  g:skillfmt_args        Extra shell arguments appended to the command,
                        including the 'formatprg' used by |gq|.

The plugin runs `skillfmt --version` before formatting and requires
`>= 0.1.0`; older or unparseable versions are refused.

Vim 7.4 NOTES

The plugin uses only Vim 7.4 features: |system()|, |tempname()|,
|writefile()|, |readfile()|, |winsaveview()| and shell redirection.  It does
not use systemlist(), jobs, timers, JSON, lambdas or |->| method syntax.
The buffer must use 'encoding' utf-8 for non-ASCII source.
